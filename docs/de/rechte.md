# Rollen und Rechte

[English](../en/permissions.md) · [Alle Dokus](../README.md)

## Serverrollen

Jeder Server hat die Rolle `@everyone`, die alle Mitglieder haben. Weitere Rollen legst du unter **Servereinstellungen → Rollen** an. Weiter oben stehende Rollen haben Vorrang und können die darunter verwalten. Niemand außer dem Besitzer kann eine Rolle ändern oder vergeben, die auf oder über der eigenen höchsten Rolle steht.

| Recht | Erlaubt |
|---|---|
| Kanäle ansehen | Kanäle sehen und Nachrichten lesen |
| Nachrichten senden | In Textkanälen schreiben |
| Dateien anhängen | Bilder und Dateien hochladen |
| Reaktionen hinzufügen | Auf Nachrichten reagieren |
| Externe Emojis verwenden | Emojis und Sticker aus anderen Servern posten |
| Nachrichten anheften | Nachrichten anheften und wieder lösen |
| Nachrichten verwalten | Nachrichten anderer löschen |
| Kanäle verwalten | Kanäle anlegen, ändern und löschen |
| Rollen verwalten | Rollen unterhalb der eigenen anlegen, ändern und vergeben |
| Server verwalten | Name, Beschreibung, Icon, Einladungen, Integrationen, Protokoll |
| Emojis und Sticker verwalten | Emojis und Sticker hochladen und löschen |
| Sprachkanälen beitreten | Sprachkanäle betreten |
| Sprechen | Mikrofon nutzen |
| Bildschirm teilen | Bildschirm oder Kamera übertragen |
| Timeouts vergeben | Mitglieder vorübergehend stummschalten |
| Mitglieder entfernen | Mitglieder mit niedrigerer Rolle kicken |
| Mitglieder bannen | Mitglieder dauerhaft aussperren |
| Einladungen erstellen | Einladungslinks erzeugen |
| Eigenen Spitznamen ändern | |
| Spitznamen verwalten | Spitznamen anderer ändern |
| Administrator | Alle Rechte, umgeht Kanalregeln |

## Kanalregeln

In den Kanaleinstellungen erlauben oder verbieten Regeln pro Rolle oder pro Mitglied einzelne Rechte für diesen Kanal. Mitgliederregeln gehen vor Rollenregeln, Verbote für `@everyone` werden durch erlaubende Rollen aufgehoben.

## Gruppenchats

Gruppen haben drei feste Rollen: Administrator (orange), Moderator (grün) und Mitglied (grau). In den Gruppeneinstellungen legst du fest, welche davon einladen, die Gruppe bearbeiten, Mitglieder entfernen, Nachrichten anderer löschen und Nachrichten anheften dürfen.
